# Design Engineering: All What You Need 🎨⚡

An open-source, interactive directory of **601 curated Design Engineering resources** across **24 categories** — from UI kits, shaders, 3D & motion libraries, and typography to AI coding agents, design systems, and publications.

🌐 **Live Site:** [https://atwalabs.github.io/design-engineering-all-what-you-need/](https://atwalabs.github.io/design-engineering-all-what-you-need/)

---

## ✨ Features

- **24 Category Tabs**: Dedicated tab for every category plus **All Resources** and **★ Saved**.
- **Instant Keyboard Search (`/`)**: Filter by resource name, domain, category, or notes in real time.
- **Keyboard Navigation (`←` / `→`)**: Quickly jump between category tabs using arrow keys.
- **Local Bookmarks (`★`)**: Star your favorite tools and references (persisted in `localStorage`).
- **Grid & Compact List Views**: Switch between rich card layout and dense list mode.
- **Dark & Light Themes**: Built-in theme toggle with zero external dependencies.
- **🎲 Surprise Me**: Open a random resource from the active tab for inspiration.

## 🚀 Running Locally

No build step or dependencies required — simply open `index.html` in any browser:

```bash
git clone https://github.com/atwalabs/design-engineering-all-what-you-need.git
cd design-engineering-all-what-you-need
open index.html
```

## 🤝 Contributing

Want to add a resource or fix a broken link?
1. Open `index.html` and scroll to the `<script id="raw-directory-data" type="text/plain">` section.
2. Add your link in standard Markdown format (`[Name](https://example.com/): optional short note`) under the appropriate `===Category` header.
3. Submit a Pull Request!
